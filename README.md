## Привет

Я **Palymer**. Пишу утилиты, которыми пользуюсь сам.

- [**LinuxDiskInfo**](https://github.com/Palymer/LinuxDiskInfo) — здоровье диска, SMART и живой I/O для Linux
- [**Winora**](https://github.com/Palymer/winora) — очистка, реестр и твики для Windows 10/11
- [**Hivepatch-Cl**](https://github.com/Palymer/Hivepatch-Cl) — Android-клиент HivePatch
- [**yandex-speed-cli**](https://github.com/Palymer/yandex-speed-cli) — замер канала через API Яндекс.Интернетометра
